1. PURPOSE

Define the persistence layer for the meeting intelligence platform, ensuring high-performance vector retrieval and robust audit trails for enterprise compliance.

3. ENTITY DEFINITIONS

  • Users: Central registry for organizational hierarchy.
  • Meetings: Temporal entities linking audio streams and extracted intelligence.
  • ActionItems: Task-based tracking for operational flow.
  • Embeddings: High-dimensional data for vector similarity search.

14. SECURITY

RBAC enforced via the `role` attribute in `Users`. Sensitive fields encrypted at rest using AES-256. Audit trails mandated for all data mutation queries.

16. PERFORMANCE

Utilizing pgvector indexes (HNSW) for `embeddings` table to ensure sub-millisecond retrieval of contextually relevant meeting segments.
